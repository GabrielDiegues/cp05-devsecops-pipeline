O contexto

Uma chave de API vazou num commit público da Arcanjo SA. A diretoria decretou: pipeline de segurança obrigatório em todos os repositórios. Este repositório é o pipeline de referência: três barreiras automáticas no GitHub Actions que impedem segredos, código vulnerável e imagens com CVE crítico de chegarem à produção.

Stack da imagem: nginx:1.30-alpine servindo este index.html estático na porta 80.

As três barreiras do pipeline

JobFerramentaO que barra
gitleaksGitleaksSegredos (chaves de API, tokens, senhas) em qualquer commit do histórico.
semgrepSemgrep (SAST)Código vulnerável, como eval() sobre entrada do usuário.
trivyTrivyImagem Docker com CVE de severidade CRITICAL nos pacotes do SO.
Provado, não prometido: cada barreira tem um Pull Request de sabotagem que a faz falhar — segredo falso, eval e imagem base desatualizada. A main permanece verde.
